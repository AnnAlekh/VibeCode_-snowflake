📖 О проекте

Что это?

AI Interviewer Platform — полнофункциональная веб-платформа для автоматизированного проведения технических интервью с использованием искусственного интеллекта для генерации задач, анализа решений и создания детальных отчетов.

Ключевые возможности:

  • 🎯 Три уровня сложности: Junior, Middle, Senior с адаптивным выбором задач
  • 🤖 AI-генерация задач: Уникальные задачи на основе Qwen LLM
  • 💻 Встроенный редактор кода: Поддержка Python, JavaScript, Java
  • 🔍 Глубокий анализ решений: Оценка корректности, оптимальности, качества кода
  • 📊 Детальные отчеты: Комплексная аналитика по всем аспектам решения
  • 🛡️ Античит-система: Защита от списывания и использования внешних инструментов
  • ⚙️ Админ-панель: Управление задачами, сессиями, кандидатами

🔄 Процесс работы системы

1. Выбор уровня

Кандидат выбирает уровень сложности: Junior, Middle или Senior

↓
2. Генерация задачи

AI генерирует уникальную задачу на основе уровня и темы. Отображается прогресс генерации в реальном времени

↓
3. Решение задачи

Кандидат пишет код в веб-редакторе. Система отслеживает время, попытки, использование подсказок

↓
4. Анализ решения

AI анализирует код: корректность, оптимальность, качество, сложность алгоритма. Запускаются тесты

↓
5. Вопросы интервьюера

AI задает адаптивные вопросы на основе решения. До 3 дополнительных вопросов на задачу

↓
6. Вторая задача (опционально)

Адаптивный выбор следующей задачи на основе результатов первой

↓
7. Финальный отчет

Генерация детального отчета с оценками, рекомендациями и аналитикой

🔧 Модули системы

TaskGenerator

Назначение: Генерация уникальных задач для интервью

  • Генерация по уровню и теме
  • Streaming-режим для отображения прогресса
  • Создание тестовых случаев
  • Поддержка разных языков программирования

SolutionAnalyzer

Назначение: Глубокий анализ решений кандидатов

  • Оценка корректности (40%)
  • Оценка оптимальности (25%)
  • Оценка качества кода (20%)
  • Анализ сложности (Big O)
  • Детальный фидбек и рекомендации

LevelAssessor

Назначение: Оценка уровня кандидата

  • Анализ решений по критериям
  • Определение соответствия заявленному уровню
  • Рекомендации по уровню

AdaptiveTaskSelector

Назначение: Адаптивный выбор задач

  • Выбор следующей задачи на основе результатов
  • Балансировка сложности
  • Учет предыдущих попыток

ReportGenerator

Назначение: Генерация финальных отчетов

  • Сводная оценка по категориям
  • Детальный анализ каждой задачи
  • Рекомендации для развития
  • Сравнение с эталонами

CodeExecutor

Назначение: Безопасное выполнение кода

  • Запуск в изолированном окружении
  • Проверка на видимых и скрытых тестах
  • Обработка ошибок и таймаутов

💼 Бизнес-логика системы

Управление сессиями интервью

  • Создание сессии: Генерация уникального ID, настройка параметров (уровень, время, количество задач)
  • Отслеживание состояния: Статусы: awaiting, active, completed, paused
  • Метрики в реальном времени: Время, количество задач, текущая оценка
  • История: Сохранение всех сессий с возможностью просмотра и анализа

Адаптивная система вопросов

  • Базовые вопросы: Стандартные вопросы для каждой задачи
  • Дополнительные вопросы: До 3 вопросов на основе анализа решения
  • Контекстные подсказки: AI может давать подсказки при затруднениях
  • Оценка коммуникации: Анализ ответов на вопросы интервьюера

Система оценки

  • Корректность (40%): Правильность решения, прохождение тестов
  • Оптимальность (25%): Эффективность алгоритма, сложность
  • Качество кода (20%): Читаемость, структура, стиль
  • Коммуникация (15%): Ответы на вопросы, объяснение решений
  • Общая оценка: Взвешенная сумма по всем критериям (0-100)

📋 Сценарии использования

Сценарий 1: Технический скрининг кандидата

Контекст: HR получил резюме кандидата на позицию Middle Developer

Процесс:

  1. HR создает сессию интервью уровня "Middle"
  2. Отправляет ссылку кандидату
  3. Кандидат проходит интервью (2 задачи, ~45 минут)
  4. AI анализирует решения и генерирует отчет
  5. HR получает детальный отчет с оценкой и рекомендацией

Результат: Объективная оценка технических навыков, экономия времени интервьюера

Сценарий 2: Массовый отбор

Контекст: Компания получила 100+ резюме на позицию Junior Developer

Процесс:

  1. Создаются сессии для всех кандидатов
  2. Кандидаты проходят интервью асинхронно
  3. Система автоматически ранжирует по результатам
  4. HR получает топ-20 кандидатов для финального интервью

Результат: Экономия 200+ часов времени, фокус на лучших кандидатах

📋 Дополнительные сценарии

Сценарий 3: Оценка внутренних сотрудников

Контекст: Компания хочет оценить технический уровень команды

Процесс:

  1. Создаются сессии для разных уровней
  2. Сотрудники проходят интервью
  3. Система генерирует аналитику по команде
  4. HR планирует обучение на основе gap-анализа

Результат: Данные для стратегического планирования развития

Сценарий 4: Адаптивное интервью

Контекст: Кандидат показал отличные результаты на первой задаче

Процесс:

  1. Система анализирует первое решение
  2. AdaptiveTaskSelector выбирает более сложную вторую задачу
  3. Кандидат решает задачу повышенной сложности
  4. Финальная оценка учитывает обе задачи

Результат: Более точная оценка реального уровня кандидата

⚙️ Технические особенности

Frontend

  • Чистый HTML/CSS/JavaScript (без фреймворков)
  • Редактор кода с подсветкой синтаксиса
  • WebSocket для real-time обновлений
  • Античит-мониторинг (clipboard, devtools)
  • Адаптивный дизайн
  • Админ-панель с аналитикой

Backend

  • Node.js + Express REST API
  • Модульная архитектура
  • Интеграция с Qwen LLM API
  • Потоковая генерация (streaming)
  • Безопасное выполнение кода
  • Хранение данных в JSON

AI Integration

  • Модель: qwen3-32b-awq / qwen3-coder-30b-a3b-instruct-fp8
  • Температура: 0.2-0.3 для точного анализа, 0.7 для генерации
  • Streaming: Постепенная генерация задач для лучшего UX
  • Контекстные промпты: Детальные промпты для каждого типа задачи
  • Обработка ошибок: Retry-логика и fallback-механизмы

Docker & Deployment

  • Docker Compose для оркестрации
  • Отдельные контейнеры для frontend и backend
  • Готовность к production-деплою
  • Переменные окружения для конфигурации

🛡️ Античит-система

Механизмы защиты:

  • Мониторинг clipboard: Отслеживание копирования/вставки кода
  • Детекция DevTools: Обнаружение открытия инструментов разработчика
  • Логирование действий: Запись всех подозрительных событий
  • Визуальные индикаторы: Отображение статуса античита в интерфейсе
  • Админ-панель: Просмотр всех античит-событий

Как это работает:

⚙️ Админ-панель

Функциональность:

  • Управление задачами: Создание, редактирование, удаление задач. Настройка видимости (public/private)
  • Мониторинг сессий: Просмотр всех активных и завершенных интервью в реальном времени
  • Управление кандидатами: Просмотр результатов, оценок, истории попыток
  • Настройки системы: Длительность интервью, количество задач, модель LLM, параметры античита
  • Аналитика: Статистика по интервью, средние оценки, процент одобрений
  • Античит-события: Просмотр всех зафиксированных подозрительных действий

Примеры данных:

  • Сессии: ID, кандидат, уровень, статус, прогресс, время
  • Кандидаты: Общая оценка, технические навыки, коммуникация, количество попыток
  • Задачи: ID, название, описание, уровень, тема, тестовые случаи
  • Отчеты: Детальные отчеты по каждому интервью
